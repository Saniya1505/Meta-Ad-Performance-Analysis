# Meta-Ad-Performance-Analysis

## 📌 Overview  
This project presents a **Meta (Facebook & Instagram) Ad Performance Dashboard** built using **Power BI**.  
It provides a comprehensive analysis of advertising performance across multiple dimensions such as engagement, conversions, demographics, and campaign effectiveness.

The dashboard is designed to help marketers and analysts **track KPIs, identify trends, and optimize ad strategies** efficiently.

---

## 🚀 Key Features  

### 📈 Performance Metrics Overview
- Impressions  
- Clicks  
- Shares  
- Comments  
- Purchases  
- Engagements  

### 📊 KPI Indicators
- Click Through Rate (CTR)  
- Engagement Rate  
- Conversion Rate  
- Purchase Rate  
- Total Budget  
- Average Budget per Campaign  

### 👥 Audience Insights
- Engagement by Gender  
- Engagement by Age Group  

### 🌍 Geographical Analysis
- Engagement distribution across countries (map visualization)  

### 📅 Time-Based Trends
- Weekly engagement trends  
- Hourly engagement patterns  
- Monthly analysis using calendar view  

### 🎯 Interactive Filters
- Platform selection (Facebook / Instagram)  
- Campaign Name  
- Target Interest  
- Dynamic measure selection  

---

## 🛠️ Tools & Technologies  

- Power BI Desktop  
- Data Modeling  
- DAX (Data Analysis Expressions)  
- Data Visualization Techniques  

---

## 📊 Insights You Can Derive  

- Identify top-performing ad formats based on engagement and conversion  
- Understand audience demographics for better targeting  
- Track campaign performance trends over time  
- Analyze budget allocation and efficiency  
- Compare performance across Facebook and Instagram
